# Sandlot Sports Camp

A multi-page marketing and registration website for Sandlot Sports Camp — a Summer multi-sport day camp for kids in Dublin, Ohio.

## 🏕️ About the Site

This site serves as the primary digital presence for Sandlot Sports Camp, providing parents and families with everything they need to learn about and register for camp.

## 📄 Pages

- **Home** — Hero landing page with camp overview and CTA
- **The Experience** — Activities grid, field trips, swimming, scuba diving, and weekly itinerary
- **The Details** — Pricing, schedule, policies, and camp FAQs
- **The Team** — Meet the coaches and staff
- **Registration** — Bookeo-integrated registration portal with camp week schedule and refund policy

## 📋 Camp Info

- **Who:** Grades 2–8 (Ages 7–13)
- **When:** 6 weeks, June 15 – July 24
- **Hours:** 9am – 4pm daily
- **Cost:** $249 per week
- **Locations:** Vary by year

## 🛠 Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Registration:** Bookeo booking platform integration
- **Backend & Deployment:** Base44

## 🔧 Local Development

```bash
npm install
npm run dev
```

> **Note:** Backend functionality requires Base44 credentials. The live site is deployed via Base44.
